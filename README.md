# Айан — мобильный прототип сервиса междугородних поездок

Айан оформлен как мобильное приложение/PWA: обязательный экран входа, регистрация пассажира или водителя, нижняя навигация, карточки рейсов, отдельная кнопка профиля сверху и профиль в виде выдвижного окна.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере для ознакомления. Для установки PWA запустите проект через HTTPS или локальный сервер (`localhost`).
3. На телефоне откройте опубликованный HTTPS-адрес и выберите «Добавить на главный экран».

## Демо-возможности

- Вход и регистрация по телефону и паролю; выбор роли пассажир/водитель доступен только при регистрации.
- Пассажир видит ближайшие рейсы, может записаться на рейс или опубликовать заявку, на которую откликаются водители.
- Водитель публикует рейсы, видит заявки на свои рейсы и заявки пассажиров, может откликаться на заявки пассажиров.
- После подтверждённой поездки пассажир может поставить оценку; рейтинг отражается в профиле и карточках водителей.
- Администратор может менять имя и роль пользователей, удалять аккаунты, публикации рейсов и заявки пассажиров, экспортировать демо-данные.
- Посылки и чат поддержки оставлены как локальные демо-разделы.

### Вход администратора в локальном демо

- Телефон: `+7 900 000-00-00`
- Пароль: `admin2026`

Администратор не показывается в списке ролей регистрации. Эти демонстрационные реквизиты нельзя использовать в настоящем публичном сервисе.

## Ограничения

Это прототип интерфейса: аккаунты, заявки, рейтинги и публикации хранятся в `localStorage` текущего браузера и не синхронизируются между устройствами. Пароли в демо также хранятся локально без безопасного хеширования. Для реального запуска необходим backend, база данных, серверная авторизация и проверка прав на сервере; демо-вход администратора следует заменить защищённой учётной записью. SMS-подтверждение телефона, платежи, реальные карты и push-уведомления не подключены.
